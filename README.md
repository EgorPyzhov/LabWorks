# LabWorksPackage (Java)

Програмний пакет з GUI (Java Swing): лабораторні роботи 1–11 в одному застосунку.

## Автор
Пижов Єгор, КН-24002б (2 підгр.), НУБіП України, варіант №12.

## Склад
- ЛР1–ЛР7 (модуль 1): вираз G(x, y, a), цикли for/while, класи, успадкування, агрегація, поліморфізм (пакет `labworks.module1`).
- ЛР8–ЛР11 (модуль 2): масив фігур, регулярні вирази, файли, БД SQLite (пакет `labworks.module2`).
- Вкладка «Про автора» з фото (`author.jpg` поруч із програмою).

## Запуск
Потрібен JDK 17+. Windows: двічі клікнути `run.bat`. Linux/macOS: `./run.sh`.

## API-документація
`javadoc.bat` створює папку `docs` (відкрити `docs/index.html`).
